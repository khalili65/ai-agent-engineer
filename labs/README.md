# Labs

Each lab is one full project. In the video, the teacher builds it step by step; here you get the finished code.

Every lab folder has the same shape:

    labs/01-support-agent/
    ├── README.md        what you build, the files, how to run it
    ├── agent.py         the agent
    ├── tools.py         the tools the agent may use
    ├── data/            small example data (bookings, rules, ...)
    └── tests/           quick tests you can run with: uv run pytest labs/01-support-agent

All labs use the same settings from the `.env` file in the repository root.
